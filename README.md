# MSClouds Blog

Static website structure for Cloudflare Pages.

## Structure

```text
cloud-blog-post/
├── index.html
├── articles.html
├── about.html
├── css/
├── js/
├── assets/
├── posts/
└── README.md
```

Place CSS files in `css/`, JavaScript files in `js/`, images and other assets in `assets/`, and blog posts in `posts/`.
